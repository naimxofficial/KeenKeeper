# 🤝 KeenKeeper

> **Friends to keep close in your life.**

KeenKeeper is a personal relationship management app that helps you stay connected with the people who matter most. Track your friends, log interactions, visualize your communication patterns, and never let an important relationship go cold again.

🌐 **Live Site:** [https://keenkeeper-naimxofficial.netlify.app/](https://keenkeeper-naimxofficial.netlify.app/)

---

## ✨ Features

| Feature | Details |
|--------|---------|
| 👥 **Friends Dashboard** | Responsive 4-column grid of all friends with photo, tags, days since contact & status badge |
| 📊 **Home Stats** | At-a-glance stats — Total Friends, On Track, Need Attention & Interactions This Month |
| 🔍 **Friend Detail Page** | Full profile with bio, email, Days Since Contact, Goal, Next Due Date, Relationship Goal & Quick Check-In |
| 📞 **Quick Check-In** | Log a Call, Text, or Video interaction directly from a friend's detail page |
| 🟢 **Status Badges** | Color-coded status per friend — On Track (green), Overdue (red), Needs Attention (yellow) |
| 🏷️ **Friend Tags** | Each friend displays categorized tags as green badges |
| ⏰ **Timeline** | Chronological log of all interactions — filter by type (Call, Text, Video) & sort newest/oldest |
| 📈 **Friendship Analytics** | Pie chart showing interaction breakdown by type (Text, Call, Video) using Recharts |
| 🔔 **Toast Notifications** | Real-time success & error feedback on all check-in actions |
| 🗂️ **Snooze / Archive / Delete** | Manage friend cards directly from the detail page |
| 🚫 **Custom 404 Page** | Styled "Lost in the wilderness" error page with a Return Home button |
| 🔗 **Active NavLink Highlighting** | Active nav items highlighted with dark green background |
| 📱 **Fully Responsive** | Mobile-friendly hamburger layout with responsive grids throughout |
| 🎨 **Dark Green Theme** | Consistent `#244D3F` dark green across nav, badges, buttons & accents |

---

## 📄 Pages & Routes

| Route | Page |
|-------|------|
| `/` | Home — Friends grid & stats |
| `/timeline` | Timeline — Interaction history with filter & sort |
| `/stats` | Friendship Analytics — Pie chart by interaction type |
| `/friendDetails/:id` | Friend Detail — Full profile & Quick Check-In |
| `*` | Custom 404 Error Page |
